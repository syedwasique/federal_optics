# Federal Optical — Product Image Clustering & Multi-Angle Integrity Audit

## Overview
This audit document provides a complete visual inventory, classification, and mapping of product images across all categories in the Federal Optical online catalog.

**Root Cause Addressed:**
Previously, angle assignment relied on directory file order / sequential index adjacency. As real photographic sessions interleave different products or shots out of order, this caused images of different products to be mistakenly merged into single items (e.g. brown lenses with gold frame merged with blue gradient lenses with gunmetal frame in Ray-Ban Scuderia Ferrari).

**Remedy Applied:**
Every single image was visually inspected for frame architecture, colorway, finish, lens tint, temple markings, and perspective angle. Images have been clustered exclusively by visual identity and ordered strictly:
1. **Front View (Hero)**
2. **3/4 Perspective Angle (Hover)**
3. **Side Profile (Temple / Hinge)**
4. **Inside Specs / Close-up Details**
5. **Folded / Alternate Perspective (if applicable)**
